# Web Search

通过 `web_search` 和 `web_read` 工具进行网页搜索和信息提取，底层使用 DeepSeek 搜索/抓取 API。

## 工作流程

1. 使用 `web_search` 搜索关键词 —— 默认在搜索请求中直接返回前几个结果的正文，**一次调用即可拿到搜索结果 + 页面内容**
2. 只有当摘要不够、或需要读取特定链接时，才用 `web_read` 单独读取
3. 汇总信息回复用户

## 搜索步骤

```
1. web_search(query="关键词") → 搜索结果（标题+URL+长摘要） + 前 3 条结果的正文
2. (可选) web_read(url="具体页面URL") → 读取指定页面正文（聚合结果不够时使用）
3. 汇总关键信息回复用户
```

## 注意事项

- 搜索关键词应简洁精准（最长 128 字符），中文搜索用中文关键词
- 除非只需要链接列表，否则保持默认 `auto_read=true`（省工具轮次、省 token）
- 如果自动返回的正文不足以回答，再对具体链接用 `web_read`
- 单次最多返回 10 条结果；搜索结果不理想时调整关键词重新搜索
- 汇总信息时注明来源
